# body.glb

A plain male base mesh used for the 3D body on the panel.

- **Source:** `male_base_mesh.glb` from <https://github.com/BoQsc/Godot-Male-Base-Mesh> (release 1.0.2), first released by orange-juice-games on itch.io.
- **Licence:** CC0 1.0 (public domain dedication). No attribution is required; it is credited here anyway.
- **Changes:** none to the file. At runtime the panel smooths the surface, splits it into body zones and gives it a translucent material coloured by each system's status.

# NASA OSDR data

`OSD-569_LSDS-7_complete_blood_count.csv` is the complete blood count of the SpaceX Inspiration4
crew, released through the NASA Open Science Data Repository (OSDR). Crew members are anonymized
(C001 to C004). Time points are days before launch (L-) and after return (R+).

- Study: OSD-569, *Whole Blood Measurements from the SpaceX Inspiration4 Mission*
  (https://osdr.nasa.gov/bio/repo/data/studies/OSD-569)
- File: `LSDS-7_Complete_Blood_Count_CBC.upload_SUBMITTED.csv`, downloaded on 2026-11-14,
  unchanged except for the file name.

ALLINKAY uses the three pre-flight white blood cell counts of crew member C001
(L-92, L-44 and L-3) as a real personal baseline. All other values in the app are synthetic.

Citation: NASA Open Science Data Repository. (2024). *Whole blood measurements from the SpaceX
Inspiration4 mission (RNA-seq, epitranscriptome, WGS, clonal hematopoiesis, CBC)* (OSD-569)
[Data set]. https://osdr.nasa.gov/bio/repo/data/studies/OSD-569
